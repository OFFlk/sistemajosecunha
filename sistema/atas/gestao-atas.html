📊 Importar XLSX de atas

▼

Importe planilhas Excel. Cada aba vira uma turma. O importador detecta automaticamente ano letivo, turno e série. Turmas com o mesmo ID são substituídas; novas são adicionadas.

📥 Importar backup JSON (merge)

▼

Importe um JSON gerado por esta página. O sistema conserva o que for idêntico, adiciona o que for novo e avisa turmas suspeitas (mesma série e ano).

💾 Exportar backup

▼

Exporta turmasDB + alunosDB do módulo de atas. Faça backup antes de qualquer limpeza.

🗑️ Apagar turmas

▼

Selecione as turmas a remover. Os bancos auxiliares (atasDB, matriculasDB, turmasMetaDB) são reconstruídos automaticamente. Turmas marcadas com ⚠️ suspeita/legado não têm arquivo de origem/aba reconhecidos — geralmente são resquícios antigos e não devem existir aqui.
