ID da turma: iO ID da turma é gerado automaticamente a partir do ano letivo e das séries — não é possível editá-lo manualmente. Como pode haver mais de uma turma com as mesmas séries (por exemplo, em turnos diferentes), uma letra (A, B, C...) é sempre adicionada ao final pra torná-lo único.

Depois que a turma é salva, o ano letivo e as séries ficam travados, porque o ID depende deles. Pra corrigir algum desses dados, o fluxo é: Gestão de dados → apague a turma → volte aqui e cadastre-a de novo. O turno e o nome podem ser alterados normalmente. —

Turmas cadastradas iEste card tem 3 filtros. Ao lado do título, o ano letivo: alterne entre os anos que já têm turmas cadastradas. Abaixo do título, o status: mostre turmas ativas, inativas ou todas. Por último, o ordenador: escolha a ordem (data de criação, nome ou série); o botão ao lado alterna entre crescente e decrescente.iAo clicar em Editar, os dados da turma voltam para o formulário e você pode alterar o nome, o turno e o professor(a). Para os demais dados, siga as dicas em ID da turma. Inativar muda o status da turma para inativa; para vê-las, troque o filtro do card de "Ativas" para "Inativas".
