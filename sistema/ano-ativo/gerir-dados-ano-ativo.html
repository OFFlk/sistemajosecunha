🗑️ Excluir aluno (registro pontual)

▼

Remove um único aluno: os dados pessoais (anoAtivoAlunos) e todas as matrículas dele (anoAtivoMatriculas, de qualquer ano — não só o ano ativo), além dos documentos anexados e do avatar (foto), se houver. Útil pra limpar dados de teste sem afetar o resto. Ação irreversível — não há como desfazer.

🗑️ Excluir turma (registro pontual)

▼

Remove uma única turma (anoAtivoTurmas) e qualquer matrícula (anoAtivoMatriculas) que ainda aponte pra ela, evitando matrícula órfã apontando pra uma turma que não existe mais. Ação irreversível.

📜 Gerar ata de turma (módulo de Atas)

▼

Cria no módulo de Atas a turma e a ata de uma turma do ano-ativo, com os alunos matriculados, o schema escolhido e as notas em branco. Só turmas de ano não ativo, com alunos, turno, nome e séries aceitas pelo módulo de Atas. Cada turma só pode ser gerada uma vez; para gerar de novo, apague a turma em Gestão de Atas. Alunos sem vínculo (elo) recebem um ID novo no módulo de Atas — a união dos IDs é feita na página de IDs.

💾 Exportar backup

▼

Exporta turmas, alunos e matrículas do módulo de ano ativo em JSON (anoAtivoTurmas, anoAtivoAlunos e anoAtivoMatriculas).

📥 Importar backup JSON

▼

Restaura um backup gerado por esta página, gravando em anoAtivoTurmas, anoAtivoAlunos e anoAtivoMatriculas. Documentos com o mesmo ID são atualizados; novos são adicionados. Backups de outro módulo (como o de Atas) são recusados antes de gravar qualquer coisa.
